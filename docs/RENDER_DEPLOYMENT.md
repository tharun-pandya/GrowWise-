# 🚀 GrowWise - Render Deployment Guide (React + FastAPI)

GrowWise uses **React + TypeScript + Vite** for the frontend and **Python FastAPI** for the backend.
**Streamlit has been completely removed.**

---

## 🔍 Understanding the `{"detail":"Not Found"}` Error

If visiting your Render URL displays:
```json
{"detail":"Not Found"}
```
### Why this happens:
1. `{"detail":"Not Found"}` is the default JSON 404 response generated by **FastAPI** when a requested route is not registered.
2. This indicates that your Render service (`growwise-local-garden-planner`) is running the **FastAPI backend**, NOT the React frontend!
3. To view your **actual React + TypeScript + Vite frontend**, the frontend must be deployed as a **Render Static Site**, which compiles your code with Vite and serves the `dist` directory.

We have now added a root handler `@app.get("/")` to FastAPI (`backend/app/main.py`) that returns backend service info (or serves `dist/index.html` if bundled).

---

## 🛠️ Recommended Setup: 2 Decoupled Services via Blueprint

The repository contains `render.yaml`, which automatically provisions both services in one step:

1. Push your repository changes to GitHub.
2. In the [Render Dashboard](https://dashboard.render.com), click **New +** → **Blueprint**.
3. Select your GitHub repository.
4. Render automatically configures:
   - **`growwise-frontend`** (Static Site):
     - Build Command: `npm install && npm run build`
     - Publish Directory: `dist`
     - Environment Variables: `VITE_API_URL` pointing to `growwise-api`
   - **`growwise-api`** (Web Service):
     - Build Command: `pip install -r backend/requirements.txt`
     - Start Command: `uvicorn backend.app.main:app --host 0.0.0.0 --port $PORT`
     - Health Check Path: `/health`

## 📋 Manual Setup in Render Dashboard (If configuring individually)

### Service 1: React Frontend (Static Site)
- **Service Type**: **Static Site** *(NOT Web Service)*
- **Name**: `growwise-frontend`
- **Root Directory**: `.` *(leave blank or period)*
- **Build Command**: `npm install && npm run build`
- **Publish Directory**: `dist`
- **Environment Variables**:
  - `VITE_API_URL`: `https://growwise-local-garden-planner.onrender.com`
  - `VITE_API_BASE_URL`: `https://growwise-local-garden-planner.onrender.com`
- **Redirects/Rewrites**:
  - Type: `Rewrite`
  - Source: `/*`
  - Destination: `/index.html`

### Service 2: Python Backend (Your Existing Web Service)
- **Service Type**: **Web Service**
- **Name**: `growwise-local-garden-planner` (your existing service)
- **Runtime**: `Python 3`
- **Build Command**: `pip install -r backend/requirements.txt`
- **Start Command**: `uvicorn backend.app.main:app --host 0.0.0.0 --port $PORT`
- **Health Check Path**: `/health`
- **Environment Variables**:
  - `PYTHON_VERSION`: `3.10.12`
  - `AI_PROVIDER_TYPE`: `offline`
  - `CORS_ORIGINS`: `*`
